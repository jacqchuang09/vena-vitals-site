# Frontend Design Skill

## Goals
- Create polished, modern, responsive marketing sites.
- Favor accessible, semantic HTML and clear component structure.
- Keep UI copy concise and user-focused.

## Style preferences
- Use clean spacing, strong hierarchy, and clear visual contrast.
- Prefer subtle motion and thoughtful interactions over heavy effects.
- Maintain consistency across sections, buttons, cards, and typography.
- Support mobile-first layouts and keyboard accessibility.

## Implementation guidance
- Prefer React + Vite + Tailwind-style utility patterns when working in this project.
- Reuse existing components from src/components/ui when possible.
- Keep files organized by feature or route.
- When changing UI, verify the build and lint commands still work.
