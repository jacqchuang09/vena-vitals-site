## Journey 1: Hospital Administrator

**Goal:** Understand value, credibility, regulatory status, and how to start a demo or pilot.

| Step | User Action | Site Response |
|---|---|---|
| 1 | Lands on homepage | Hero explains continuous, noninvasive BP and shows demo CTA |
| 2 | Scans trust bar | Sees OR patients, arterial-line validation, regulatory status, UCI origin |
| 3 | Reads problem section | Understands cuff gaps and arterial-line burden |
| 4 | Checks evidence strip | Moves to Clinical Evidence page |
| 5 | Reviews Partner With Us | Sees economic case, pilot path, FAQ, downloadable assets |
| 6 | Requests demo | Completes demo form |
