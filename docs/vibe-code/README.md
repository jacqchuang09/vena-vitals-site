# Vibe Code Docs Index

This folder is the working instruction set for building the Vena Vitals marketing site with an AI coding agent.

## How To Use These Docs

1. Read `master-plan.md` to understand what we are building and why.
2. Read `implementation-plan.md` to understand the build order.
3. Use the color, font and spacing tokens in `src/styles.css` before touching layout, color, spacing, typography, or animation.
4. Read `user-journeys.md` before changing page structure or CTAs.
5. Read `rules.md` before asking an agent to work.
6. Read the root `README.md` and `content/README.md` for where everything lives.

## Blue Edit Markers

Anything shown as:

<span style="color:#0B63CE; font-weight:700;">[EDIT NEEDED: replace or confirm this item]</span>

is not final. It needs a human edit, confirmation, source, citation, permission, or decision.

## Suggested Agent Prompt

```text
Read CLAUDE.md, README.md, content/README.md and the docs in docs/vibe-code. Then make this change: <describe it>. Run the required checks, open a pull request, and report what changed and how to test it.
```
